# Doccolabs Homebrew Tap

## Network Pulse (macOS 26+)

```bash
brew tap adisapir/tap
brew trust --cask adisapir/tap/network-pulse
brew install --cask adisapir/tap/network-pulse
```

Homebrew refuses casks from third-party taps until they are trusted, hence the `brew trust` step.
The app updates itself; to upgrade through Homebrew use `brew upgrade --cask --greedy network-pulse`.

`Casks/network-pulse.rb` is generated by the Network Pulse release script. Do not edit it by hand.
